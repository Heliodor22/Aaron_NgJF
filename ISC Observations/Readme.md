# ISC Internship – Attack Observations

This section documents selected attack observations, malware activity, and investigation findings identified during my internship with the SANS Internet Storm Center (ISC).

The write-ups focus on analysing suspicious network activity, attacker behaviour, exploitation attempts, indicators of compromise, and relevant security observations gathered during the internship.

One of my observations was published as an ISC Diary entry:

- [RedTail Malware Exploiting PHP CGI Vulnerability – SANS Internet Storm Center](https://dshield.org/diary/33326)

These materials are intended to demonstrate practical experience in network traffic analysis, threat investigation, malware analysis, and technical documentation.
