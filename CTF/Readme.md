# National Cyber League Cyber Skyline CTF Write-Up

## Overview

This repository documents my participation in the **National Cyber League (NCL) Cyber Skyline Competition**, where I developed and applied practical cybersecurity skills across blue team analysis, digital forensics, network security, reconnaissance, web security, cryptography, password security, and exploitation challenges.

The purpose of this write-up is to showcase my learning process, practical problem-solving approach, and cybersecurity skill development. It is written as a portfolio artifact for cybersecurity roles such as **SOC Analyst, Cybersecurity Analyst, DFIR Analyst, Incident Response Analyst, and Security Engineer**.

> Note: This repository does not include live flags, restricted challenge answers, or content intended to violate competition integrity. The write-up focuses on skills demonstrated, learning outcomes, and high-level methodology.

## Participation Summary

**Platform:** National Cyber League / Cyber Skyline  
**Participation Period:** September 2024 – May 2026  
**Competition Format:** Individual and team-based cybersecurity challenges  
**Focus Areas:** Blue team analysis, forensics, network traffic analysis, vulnerability identification, OSINT, password security, web security, and exploitation

## Skills Practised

### Log Analysis & Security Monitoring

- Reviewed logs to identify suspicious activity and possible indicators of compromise.
- Practised correlating events across different data sources.
- Developed a stronger understanding of how analysts separate meaningful activity from noise.

### Network Traffic Analysis

- Analysed packet captures and network artefacts.
- Reviewed protocols, source and destination traffic, ports, and connection behaviour.
- Practised identifying abnormal traffic patterns and suspicious communication.

### Digital Forensics

- Investigated files, metadata, timestamps, and forensic artefacts.
- Practised evidence-based analysis and structured investigation.
- Developed stronger familiarity with forensic thinking and timeline reconstruction concepts.

### Reconnaissance & Enumeration

- Practised structured enumeration of systems, services, and exposed information.
- Used common reconnaissance techniques to identify useful clues and attack paths.
- Reinforced the importance of careful note-taking and methodical investigation.

### Web Security

- Reviewed common web security weaknesses and exploitation paths.
- Practised identifying vulnerable inputs, authentication issues, and insecure configurations.
- Reinforced awareness of OWASP-style vulnerability categories.

### Password Security

- Practised password analysis, hash identification, and password-cracking concepts.
- Strengthened understanding of password policy, weak credentials, and credential-based risk.

### OSINT

- Used open-source information gathering techniques to solve investigation-style challenges.
- Practised validating information from multiple sources.
- Reinforced the importance of accuracy and context during investigations.
